# CyberDict

Current release: **v1.1**

CyberDict is a community cybersecurity dictionary and interactive knowledge explorer for offensive security, defensive security, purple teaming, identity, web security and AI security.

## Features

- Searchable cybersecurity terminology
- Essential visual explainers
- Dedicated term pages with full size visual learning aids
- Category based browsing
- Related term discovery
- Static first deployment for Cloudflare Workers

## Run locally

Serve the `public` directory with any static web server.

## Deploy

```bash
npx wrangler deploy
```
